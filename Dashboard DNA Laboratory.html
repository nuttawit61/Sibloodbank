🧠 บทวิเคราะห์แนวโน้มสถิติ DNA Laboratory และการบริหารคุณภาพเชิงยุทธศาสตร์ (2564 - ปัจจุบัน)

วิเคราะห์เปรียบเทียบปริมาณงาน HLA-DNA Typing, ADR, Luminex และ NGS

📊 บทวิเคราะห์จากฐานข้อมูลสถิติห้อง DNA Laboratory (2564 - 2569)

  • KT HLA-DNA Typing เติบโตอย่างต่อเนื่อง: ปริมาณการตรวจ KT Class I และ Class II รวม เพิ่มขึ้นอย่างมีนัยสำคัญตั้งแต่ปี 2564 (รวม ~91 ราย/ปี สำหรับ Class I) ไปสู่ปี 2567-2568 ที่กว่า 300 ราย/ปี สะท้อนการขยายตัวของโปรแกรม Kidney Transplantation ที่ศิริราช
  • ADR Typing — B*58:01 เป็น allele หลัก: ในกลุ่มการตรวจ ADR (Adverse Drug Reaction Screening) B*58:01 มีสัดส่วนสูงสุดเฉลี่ยกว่า 50-65% ของ ADR ทั้งหมดในทุกปี ตามด้วย B*15:02 และ B*57:01 ซึ่งสอดคล้องกับข้อมูลทางระบาดวิทยาในประชากรเอเชียตะวันออกเฉียงใต้
  • Luminex HLA Antibody เพิ่มขึ้นมากในปี 2568: ปริมาณ Luminex รวมปี 2568 อยู่ที่ ~1,773 ราย เพิ่มจากปี 2566 (~1,231 ราย) อย่างมีนัยสำคัญ โดยเฉพาะ Single Antigen HLA Class I และ Class II ที่เพิ่มตามความต้องการ post-transplant monitoring

🌐 แนวทางการพัฒนาและการวิจัยห้อง DNA Laboratory

  • การนำ NGS HLA Typing เข้าสู่บริการ (2569): การเริ่มให้บริการ Next Generation Sequencing (NGS) สำหรับ HLA Typing ใน KT Patient (18 ราย/เดือน มี.ค. 2569) เป็นก้าวสำคัญในการเพิ่มความละเอียดของผล High-resolution typing ลดข้อผิดพลาดจาก allele ambiguity และเพิ่มคุณภาพการจับคู่ผู้รับ-ผู้บริจาค
  • KIR Genotyping สำหรับ BMT Optimization: ข้อมูล KIR (Killer-cell Immunoglobulin-like Receptor) Genotyping ช่วยพยากรณ์ Graft-versus-Leukemia effect ใน BMT และลดความเสี่ยง Graft failure โดยเฉพาะในผู้ป่วยมะเร็งโลหิตวิทยา
  • Luminex MICA Genotype: การตรวจ MICA (MHC Class I Chain-related Protein A) มีบทบาทสำคัญในการ monitoring Anti-MICA antibody ซึ่งสัมพันธ์กับ Antibody-mediated rejection (AMR) โดยเฉพาะหลังการปลูกถ่ายไตและไขกระดูก
💡 ข้อเสนอแนะเชิงยุทธศาสตร์เพื่อการพัฒนาประสิทธิภาพห้อง DNA Laboratory
  1. ขยาย NGS HLA Typing ครอบคลุม BMT Donor: ปัจจุบัน NGS ให้บริการสำหรับ KT Patient เป็นหลัก ควรขยายไปยัง BMT Donor เพื่อเพิ่มความแม่นยำในการ matching และลดโอกาสเกิด Graft-versus-Host Disease (GvHD)
  2. พัฒนาระบบรายงานผล ADR แบบ Real-time: เชื่อมต่อระบบรายงาน HLA-B*58:01 และ B*15:02 กับระบบสารสนเทศโรงพยาบาล (HIS) เพื่อแจ้งเตือนแพทย์ก่อนสั่งยา allopurinol และ carbamazepine ลดอุบัติการณ์ SJS/TEN
  3. พัฒนา Luminex C1q testing เพิ่มเติม: Complement-fixing antibody testing (SA C1q) มีประโยชน์สูงในการระบุ DSA (Donor Specific Antibody) ที่เป็น complement-binding ควรพิจารณาขยายจำนวนการตรวจเพื่อ risk stratification ก่อน/หลังการปลูกถ่าย
